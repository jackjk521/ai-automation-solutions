🔀 Universal LLM Router (×3)

The same Code node pattern is reused for Industry Overview, Lead Scoring, and MVP HTML generation. Switch provider by changing LLM_PROVIDER, LLM_BASE_URL, LLM_MODEL, LLM_API_KEY — no workflow edits needed.

⚡ Circuit Breaker

Before each lead is enriched, a Code node reads $workflow.vars.errorCount. If errors ≥ MAX_ERRORS_BEFORE_ABORT (default 5), the Check Abort node jumps directly to the Email Digest, skipping remaining leads gracefully.

⏳ Bounded Apify Poll

A for loop inside a single Code node polls the Apify run status up to MAX_APIFY_POLL_ATTEMPTS times (default 15) with 10-second waits. No n8n Loop nodes — prevents infinite execution hangs.

📊 Accumulator Pattern

Each scored lead is pushed into $workflow.vars.scoredLeads. Once all leads complete, the array is sorted by total score (tiebreak: non-local businesses first, then expansion_score). Only the top TOP_LEADS_KEPT proceed.

🎯 Score Gate

Only leads with total ≥ SCORE_THRESHOLD (default 70/100) get an AI-generated MVP HTML page deployed to Vercel. Lower-scoring leads are still saved to Sheets but skip the Vercel step and route directly to the Email Digest.

⚠️ Single Error Sink

Every node's error output is wired to the same Error Logger node. It increments $workflow.vars.errorCount and appends to the Errors tab in Google Sheets — so every failure is logged even when the circuit breaker hasn't triggered yet.

🔢 Scoring Dimensions (100 pts)

tech_score (25) — modern stack vs legacy CMS
seo_score (25) — PageSpeed + PageRank signals
brand_score (25) — site quality + brand clarity
sales_readiness (25) — decision-maker accessibility
+ local_business flag (filters pure local from outreach list)

📁 Google Sheets — 3-Tab Schema

Config tab — niche, region, active flag, run schedule
Leads tab — all scored leads with Vercel URLs + scores
Errors tab — timestamped error log per run
